# 🎯 Ações no Texas Hold'em

Durante uma rodada de apostas, os jogadores podem realizar diferentes ações dependendo da situação.

## 📋 Principais ações

| Ação | Significado |
|---|---|
| **Fold** | Desistir da mão e deixar de disputar o pote. |
| **Check** | Passar a vez sem apostar, quando não existe uma aposta para pagar. |
| **Bet** | Fazer uma aposta quando ainda não existe uma aposta na rodada. |
| **Call** | Igualar a aposta atual para continuar na mão. |
| **Raise** | Aumentar uma aposta que já foi realizada. |
| **Re-raise** | Aumentar novamente depois de outro jogador ter realizado um raise. |
| **All-in** | Colocar todas as fichas restantes na mão. |

---

## ⚖️ Diferenças importantes

### Check vs. Call

**Check**

O jogador passa a vez sem colocar fichas adicionais.

Só é possível quando não existe uma aposta para pagar.

**Call**

O jogador coloca fichas suficientes para igualar a aposta atual.

### Bet vs. Raise

**Bet**

É a primeira aposta feita em uma rodada em que ainda não existe uma aposta.

**Raise**

É um aumento feito sobre uma aposta que já existe.

---

## 🔄 Exemplo de uma rodada

Imagine que estamos no Turn:

1. Jogador A → **Check**
2. Jogador B → **Bet 100**
3. Jogador C → **Fold**
4. Jogador A → **Call 100**

O Jogador C deixa a mão.

Os jogadores A e B continuam disputando o pote.

---

## 🏁 Quando todos desistem

Se um jogador apostar e todos os outros jogadores desistirem:

- A mão termina imediatamente.
- O jogador restante vence o pote.
- Ele não precisa mostrar suas cartas.
- As fichas que já estavam no pote ficam com o vencedor.
